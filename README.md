# 복식 테니스 랭킹포인트 앱 (Streamlit)

## 1) 구성 파일
- players.csv : 선수 이름과 급수(예: 4단, 2급)
- matches.csv : 누적 경기 기록(앱이 자동 생성/누적)
- streamlit_app.py : 실행 파일

## 2) 실행 방법
1. Python 3.10+ 설치
2. 패키지 설치
   pip install streamlit pandas
3. 폴더로 이동 후 실행
   streamlit run streamlit_app.py

## 3) 사용 방법
- '오늘 경기 입력' 표에 승리팀(왼쪽), 패배팀(오른쪽), 스코어를 입력
- 자동 계산된 승점/패점을 확인 후 '저장' 버튼 클릭
- 아래 '누적 랭킹보드'에서 전체 누적/특정 날짜(오늘 승패점) 확인 가능

## 4) 점수 로직(요약)
- 급수 → 점수: 9급=1 ... 1급=9, 1단=10 ... 9단=18
- 팀 급수합 차이(diff) → handicap = diff * 0.25
- 기본: 승리팀 +1.5, 패배팀 -1.0
  - 강팀 승리: 승점 = 1.5 - handicap / 패점 = -1.0 + handicap
  - 약팀 승리: 승점 = 1.5 + handicap / 패점 = -1.0 - handicap
- 스코어 보너스: (승리게임-패배게임 - 3) * 0.1, 단 3게임차 이하이면 0
  - 승점에 +bonus, 패점에 -bonus
